Each commit leaves `uv run ruff check . && uv run pytest -q` green (browser-marked tests may skip when Chrome is absent; they must pass when `BU_CDP_URL` points at a Chrome). Messages: English, conventional prefix, imperative, ≤ 72 chars, body only for a non-obvious why, no trailers.

A reference implementation of the loop exists outside the repo (jev-ultrafast clone, path in the brief). Adapt, do not paste; the history must read as an incremental build with tests in every commit.
