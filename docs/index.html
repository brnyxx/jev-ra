How it works

One typed decision per step instead of one LLM call per step.

01

Snapshot

One CDP call reads the visible text and every interactive control into an indexed table, with identity guards so a stale page can never be clicked.

02

Decide

Jev answers, in one ~300 ms request: which operation, which element, which of your values goes in that field, did the last step work, is the goal done.

03

Act or escalate

Trusted input through the DevTools protocol. If it is stuck, needs a value, or cannot verify done, it hands your agent the page and the top candidates.

your agent  ──goal, values──▶  jev-ra
                                  │ observe (1 CDP call)
                                  │ decide  (1 Jev call, ~300 ms)
                                  │ act     (trusted input)
                                  │ verify  (deterministic diff)
                                  ▼
your agent  ◀──result | escalate(reason, candidates, page text)──

Install

One line. Works with the OpenRouter key you already have; no TypeSafe account required.

export OPENROUTER_API_KEY=sk-or-...
uvx jev-ra install claude
# then in Claude Code: "search the web for X and summarise"
export OPENROUTER_API_KEY=sk-or-...
uvx jev-ra install codex
# Codex asks you to trust the new MCP server once
export OPENROUTER_API_KEY=sk-or-...
npx -y jev-ra install claude   # or: install codex
{
  "mcpServers": {
    "jev-ra": { "command": "uvx", "args": ["jev-ra", "mcp"], "env": { "OPENROUTER_API_KEY": "sk-or-..." } }
  }
}
uvx jev-ra run https://en.wikipedia.org/wiki/Main_Page \
  "Find and open the article about Gödel's incompleteness theorems" --json
uvx jev-ra search "python 3.12 release date" --goal "the exact release date, with source"
uvx jev-ra doctor

What it will not do (yet)

These escalate to your agent with a reason instead of guessing.

Out of scope in v0.1

  • Cross-origin iframes (same-origin and open shadow roots work)
  • Canvas-drawn UIs
  • File uploads
  • Captchas, bot walls
  • Multi-tab workflows

By design

  • Never types a value your agent did not supply (no guessed personal data)
  • Never turns model output into selectors or JavaScript
  • Never reports done without a visible check
  • Sends visible page text to Jev; never file bodies or screenshots
