# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
Developers who drive a CLI coding agent (Claude Code, Codex, Cursor, Cline, any MCP client) and need that agent to use a real browser: fill forms, sort and filter lists, search and cite, navigate sites. They evaluate tools by running one install command and watching a task finish.

## Product Purpose
jev-ra is an MCP server and CLI that lets a coding agent drive Chrome. TypeSafe Jev, a typed decision model, picks the operation and the element for each step in about 300 ms; the host agent plans, supplies every typed value, reads the page, and takes over when jev-ra escalates. Success on the landing page: the visitor copies the install command (`uvx jev-ra install claude`).

## Positioning
Faster and more accurate than browser-use on the same tasks, measured on the same machine and Chrome: 8.5x on Wikipedia, 7.5x on Google Flights, 4.0x on Olive Young (medians of 5 verified runs); on the same 40 real-site tasks, 85 % pass at 3.1 s median against browser-use's 72 % at 19.4 s. No second LLM in the loop; it never invents a value it was not given, and every stop comes back with a reason and candidates.

## Operating Context
Terminal-first. The visitor arrives from GitHub, PyPI, npm or a link, reads the numbers, copies one command, and runs `jev-ra doctor`. Distribution: PyPI and npm (same version), MIT, GitHub brnyxx/jev-ra. The page is a single static file on GitHub Pages in four languages (en, ko, ja, zh-CN).

## Capabilities and Constraints
14 MCP tools; CLI with run/search/open/observe/extract/serve/trace/profile/doctor/install; ten escalation reasons (needs_value, stuck_loop, unverified_done, stale, invalid_decision, too_many_controls, provider_error, budget, blocked, blocked_by_site). Out of scope: cross-origin iframes, canvas UIs, file uploads, captchas, multi-tab workflows. Current version line: 0.2.x (1.0 is reserved for the commercial launch).

## Brand Commitments
Name jev-ra (read as "zebra" in Korean). Zebra-stepping-out-of-a-browser mark in `assets/` (mark, tile, logo, hero), generated by `assets/source/build_brand.py`. Palette ink #0B0F14, paper #F6F4EF, one accent amber #FFB703 (see `assets/README.md`); the mark always faces right.

## Evidence on Hand
Measured benchmarks and raw rows in `docs/BENCHMARKS.md` and `docs/benchmarks/`; demo GIFs in `assets/demo/`; a recorded run replayed by `docs/assets-site/demo.js`. No customer logos, testimonials, pricing or user counts exist; none may be invented.

## Product Principles
- Every number on the page is measured and linked to its raw rows.
- The agent stays in charge: jev-ra never guesses a value and says why it stopped.
- One command to try it; one decision per step.
- Honest limits are part of the pitch.
